# 称号导入完整教程（fengsui_titles 版）

本教程以现有 `packages/fengsui/pkg/fengsui_titles/` 为模板，从零加一条称号（静态 + 动态）的全部步骤。
照着做一遍，最快 10 分钟能出成品。

---

## 一、先搞懂三层结构

称号是「服务端定义」+「客户端外观」两套东西，靠**样式代号**对接：

| 文件 | 谁读 | 作用 |
| --- | --- | --- |
| `title_pack.json` | **服务端**（freekill-asio） | 注册称号定义：`id`（稳定 ID）、`title`（显示文字）、`style`（样式代号）。`title load` 读这个 |
| `styles.lua` | **客户端** Lua | 注册样式：`["样式代号"] = { title, border, background, color, fontSize, width, height, component, backgroundMode }` |
| `qml/*.qml` | **客户端** QML | 真正的画面：图片、动画、文字回退 |
| `images/*.png` | 客户端 | 横幅底图 / 动画图集 / 海报帧 |
| `init.lua` | 客户端 | 包声明，把 `styles.lua` 的内容灌进 `Fk.title_styles` |

关键点：**`title_pack.json` 里的 `style` 必须等于 `styles.lua` 里的 key**，否则服务器认这个称号、客户端找不到外观，会显示默认灰框。

```

```

## 三、步骤 1：准备横幅素材

1. **尺寸**：宽高比 3:1 ~ 3.2:1 最稳（例如 1920×640、2160×720）。显示框固定 **110×30**，素材会被竖向裁掉一部分。
2. **格式**：PNG，**带透明通道**（RGBA）。白底/黑底素材必须先抠图，否则深色界面会看到白框、浅色界面会看到黑框。
3. **留边**：文字上下各留至少 8% 透明空间，方便 `cropBias` 调取景。
4. **命名**：小写英文 + 下划线，例如 `qingkui_banner.png`。

抠图小技巧（Pillow 边缘泛洪，处理纯色底）：

```python
from PIL import Image
im = Image.open("src.jpg").convert("RGBA")
# 从四角泛洪，把与角点颜色接近的像素设为透明（阈值 14 左右）
# 之后对 alpha 边缘做 0.8px 羽化，避免锯齿
```

## 四、步骤 2：写 QML 组件

复制 `qml/QingkuiTitle.qml`，改 5 处即可。核心结构：

```qml
import QtQuick
import QtQuick.Window

Item {
  id: badge
  property string title: "你的称号文字"      // ① 默认文字
  property bool motionEnabled: true           // 系统会传进来，关闭动画时静止
  implicitWidth: 110                          // ② 固定 110×30
  implicitHeight: 30
  readonly property real displayScale: Math.max(0, Math.min(width / implicitWidth,
                                                          height / implicitHeight))
  readonly property string displayTitle: title.replace(/^【|】$/g, "")
  readonly property bool standard: displayTitle === "你的称号文字"   // ③ 服务器没改名才显示图
  readonly property real zoom: 0.9            // ④ 框内缩放（0.9 = 略留边）
  readonly property real cropBias: 0.4        // ⑤ 竖向取景：0 顶、1 底、0.5 居中

  Item {
    id: frame
    anchors.centerIn: parent
    width: badge.implicitWidth * badge.displayScale * badge.zoom
    height: badge.implicitHeight * badge.displayScale * badge.zoom
    clip: true                                 // 必须 clip，否则图片溢出框外

    Image {
      width: frame.width
      height: width * 640 / 1920               // 素材原始宽高比
      y: -(height - frame.height) * badge.cropBias
      source: "../images/your_banner.png"
      fillMode: Image.Stretch
      smooth: true
      mipmap: true
      visible: badge.standard
    }

    // 服务器改名 / 图片加载失败时的纯文本回退（必须有，否则别人改了名会显示空白）
    Rectangle {
      anchors.fill: parent
      radius: 3 * badge.displayScale
      color: "#0e2a26"
      border.color: "#4db89b"
      border.width: Math.max(1, badge.displayScale)
      visible: !badge.standard
      Text {
        anchors.fill: parent
        anchors.margins: 3 * badge.displayScale
        text: badge.displayTitle
        textFormat: Text.PlainText
        font.family: "serif"
        font.bold: true
        font.pixelSize: 13 * badge.displayScale
        color: "#eafff7"
        horizontalAlignment: Text.AlignHCenter
        verticalAlignment: Text.AlignVCenter
        elide: Text.ElideRight
      }
    }
  }
}
```

**取景调法**：素材铺满 110×30 需竖裁的比例，就是 `cropBias` 能调的区间。
文字被裁了 → 往能露出文字的方向调；脸被裁了 → 同理。反复试 3~5 次通常就定稿。

## 五、步骤 3：注册样式（styles.lua）

在 return 的表里加一条，key 用 **包名.样式名**：

```lua
["fengsui_titles.yourname"] = {
  backgroundMode = "component",        -- 用 QML 自带底板；纯文字样式别写这行
  title = "你的称号文字",               -- 仅单机预览用，不覆盖服务器文字
  border = "#4db89b",                  -- 回退边框色
  background = "#0a2330",              -- 回退底色
  color = "#eafff7",                   -- 回退文字色
  fontSize = 13,
  width = 110, height = 30,            -- 111×30 是统一显示框，一般不改
  component = "packages/fengsui/pkg/fengsui_titles/qml/YourTitle.qml",
}
```

`component` 路径规则（服务端会校验）：
- 必须是**相对游戏根目录**的路径，从 `packages/` 开头；
- **不能**含 `..`、协议头（`file://`）、盘符（`C:/`）；
- 写错不会崩，只是退回纯文字样式。

## 六、步骤 4：写清单（title_pack.json）

两处都要加：

```json
{
  "version": 1,
  "name": "fengsui_titles",
  "styles": {
    "fengsui_titles.yourname": "你的称号文字"
  },
  "titles": [
    { "id": "yourname", "title": "你的称号文字", "style": "fengsui_titles.yourname" }
  ]
}
```

规则：
- `name` 必须等于加载时的包名（`fengsui_titles`）；
- `id` 是**稳定 ID**，一旦发放给玩家就不能改（改了等于换了另一个称号，玩家原来的会被当成未拥有）；
- 每条 `style` 必须已在 `styles` 里声明；
- 上限：256 KiB、512 个样式、512 条定义。

## 七、步骤 5：加载与发放

服务端控制台（游戏内按 `~` 或其他绑定的控制台键）：

```text
title load fengsui_titles          # 加载清单并注册定义（不发放）
title grant yourname 玩家账号      # 发放给指定账号（可跟多个账号，空格分隔）
title show 玩家账号                # 查看该账号拥有/装备情况
title reload                       # 改完清单后热重载，无需重启
title revoke yourname 玩家账号     # 收回
title unload fengsui_titles        # 临时停用整个包的称号（不删除拥有记录）
```

发放后**不会自动装备**，玩家自己到「个人信息」里选择装备。

**单机测试不用发**：本机启动会遍历 `Fk.title_styles` 自动列出所有已加载样式，可直接预览。

## 八、动态称号怎么做

两条路，按需选：

### 路线 A：图集（美术做好了帧动画）

1. 把动画导出为**定宽等高、按网格横向排列**的 PNG 图集：例如 36 帧排成 6×6，每格 440×120；
2. 再导一张静态海报帧（`*_poster.png`）用于动画未就绪/关闭动画时显示；
3. QML 里用 `NumberAnimation` 驱动一个 `index`，按 `index % 列数` 和 `Math.floor(index / 列数)` 切格；
4. `duration` 设成循环周期（如 2400ms）。

### 路线 B：纯 QML 程序化动画（不用图集，推荐）

参考 `qml/QingkuiDynTitle.qml`：静态底图 + 叠加层动画。常用元素：

- **雾气/光晕**：`RadialGradient` + `SequentialAnimation`（位移 + 透明度双动画，`InOutSine` 缓动，各团错峰）；
- **流光带**：旋转的 `Rectangle` + `linearGradient`，`NumberAnimation` 单向扫过；
- **粒子**：`Repeater` + `model` 参数数组，每粒 `y` 从底到顶、透明度淡出，`delay` 错开。

**必踩的坑**：单向循环动画**必须写显式 `from`**，否则循环回到起点时是零长度动画，看起来「只播一遍就停了」：

```qml
NumberAnimation on y {
  from: frame.height + 2      // 必须有
  to: -4
  duration: 3200
  loops: Animation.Infinite
}
```

所有动画都要挂 `running: badge.motionEnabled && badge.standard`，隐藏或关动画时停住（省电，也是官方规范）。

## 九、常见问题速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 客户端显示灰框 / 默认徽标 | `styles.lua` 没有对应 key，或 key 与清单 `style` 不一致 | 两边字符串逐字对齐 |
| 图片不显示、只有底框 | `component` 路径错（缺 `packages/` 前缀、含 `..`、盘符） | 改成 `packages/...` 相对路径 |
| 图片溢出框外 | 外层 `Item` 少了 `clip: true` | 加上 |
| 别人装了但显示自己写的名字 | 没做 `standard` 判断 | 用 `displayTitle === "默认文字"` 判断后回退纯文本 |
| 动效循环一遍就停 | 单向动画缺 `from` | 补显式 `from` |
| 横幅有白边/黑边 | 素材没抠透明 | 重新抠图转 RGBA |
| 加了称号但列表里没有 | 没 `title load`/`title reload`，或客户端没重载扩展 | 先 reload，再重启客户端 |
| 改了文字后玩家丢失称号 | 改了 `id` | `id` 永远不要改，只改 `title` |

## 十、交付前自检清单

- [ ] 素材是 RGBA PNG，宽高比 ≈3:1，无白/黑底残留
- [ ] QML 里 `implicitWidth/Height` = 110/30，`clip: true`，有纯文本回退
- [ ] 动画都写了 `motionEnabled` 开关，单向循环都有 `from`
- [ ] `styles.lua` 的 key 与 `title_pack.json` 的 `style` 完全一致
- [ ] `component` 路径从 `packages/` 起，无 `..`、无盘符
- [ ] `id` 与已有称号不重复
- [ ] `title load` → `title grant` → 玩家装备，全流程走通
- [ ] 服务器把称号改成别的名字时，显示纯文本而不是图内原名
