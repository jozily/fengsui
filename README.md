# 烽燧燎原

新月杀 0.5.20 国战扩展，包含以下子包：

- `fengsui_hebi`：烽燧燎原-合璧，包含 47 名武将。
- `fengsui_liwu`：烽燧燎原-离骛，包含中立者、周宣、陈寿、孙鸢、刘徽和王惠风，共 10 名武将。
- `fengsui_shiyi`：烽燧燎原-拾遗，包含辛宪英、郭图、孙鲁班、王异和 SP 司马攸，共 5 名武将。
- `fengsui_card`：烽燧燎原-卡牌。
- `fengsui_effect`：国战动画、图片与背景音乐资源。

本扩展依赖官方 `hegemony` 提供的国战规则与工具模块。扩展内的兼容层承载烽燧所需的国战规则扩展、特效路径重定向，以及紫凤衔佩、孙秀、杨骏等官方武将的补充语音，不需要修改官方 `hegemony` 文件。
