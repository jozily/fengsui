# 烽燧燎原

新月杀国战扩展，当前版本共 82 张武将牌：

- `fengsui_hebi`：烽燧燎原-合璧，40 张武将牌。
- `fengsui_liwu`：烽燧燎原-离骛，23 张武将牌。
- `fengsui_shiyi`：烽燧燎原-拾遗，19 张隐藏武将牌，包含学园都市角色。
- `fengsui_cards`：烽燧燎原-卡牌。
- `fengsui_effect`：国战动画、图片与背景音乐资源。
- `fengsui_mode`：燎原之战模式。

将本仓库放置于新月杀的 `packages/fengsui` 目录。当前本地使用新月杀 0.5.22。

本扩展依赖官方 `hegemony` 提供的国战规则与工具模块。扩展内的兼容层承载烽燧所需的国战规则扩展、特效路径重定向及补充语音，无需修改官方 `hegemony` 文件。
